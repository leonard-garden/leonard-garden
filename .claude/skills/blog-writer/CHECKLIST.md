# Pre-output Checklist

Before saving the file, go through EVERY item. Fail any item → REVISE, do not output.

## ✅ Structure (Parts 0-10)

- [ ] All 10 parts present?
- [ ] TL;DR exactly 3 sentences (no more, no less)?
- [ ] Part 1 has 1 specific story, not generic?
- [ ] Part 2 distinguishes from easily-confused concepts?
- [ ] Part 3 has ASCII diagram or step-by-step?
- [ ] Part 4 has ≥2 runnable examples?
- [ ] Part 5 has exactly 3 scenarios?
- [ ] Part 6 has ≥2 anti-patterns + alternatives?
- [ ] Part 7 has ≥3 gotchas?
- [ ] Part 8 has ≥3 connections?
- [ ] Part 9 has 5 OPEN questions (no Y/N, no multiple choice)?
- [ ] Part 10 has clear acceptance criteria?
- [ ] Self-test answers at THE VERY END?

## ✅ Content

- [ ] Every technical claim has evidence or reasoning?
- [ ] Numbers (pricing, versions, limits) verified?
- [ ] NO fabricated commands/APIs?
- [ ] Code examples runnable, not pseudo-code?
- [ ] At least 1 "painful" real-world gotcha?

## ✅ Style

- [ ] Length 1200-1800 words?
- [ ] NO clichéd phrases (check anti-patterns in STYLE_GUIDE)?
- [ ] NO filler words?
- [ ] Sentences short, no sentence with ≥3 clauses?
- [ ] Uses "you", not "we"?
- [ ] Bold used ≤5 times?

## ✅ Connections

- [ ] Links to ≥3 other keywords?
- [ ] Each connection clearly marked "already covered" / "coming up"?

## Verdict
- All ✅ → save file
- Any ❌ → revise, re-check from top
- More than 5 failures → structure is likely wrong from the start, rewrite
