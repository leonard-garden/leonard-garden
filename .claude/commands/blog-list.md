# /blog-list Command

## Workflow

1. Đọc `progress.md`
2. Tính:
   - Tổng đã written / 30
   - Đã read / 30
   - Đã làm exercise / 30
   - Keywords cho tuần hiện tại (theo timeline gợi ý)
3. Liệt kê:
   - 5 keyword **next up** (chưa làm)
   - 3 keyword **cần review D+7**
   - 3 keyword **cần review D+30**
4. Output dạng table dễ scan
